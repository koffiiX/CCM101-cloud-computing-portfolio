# Laboratory 1: Welcome to the Cloud

## Cloud Concepts & Reflection Paper

### 1. Cloud Services I Use Regularly
* **Google Drive:** Software as a Service (SaaS) deployed on a Public Cloud. It provides a fully managed interface for document storage and real-time collaboration without requiring users to manage physical storage or cloud servers.
* **Canva:** Software as a Service (SaaS) deployed on a Public Cloud. It offers a complete online graphic design workstation, abstracting all underlying compute engines, asset rendering, and database management.
* **Netflix:** Software as a Service (SaaS) deployed on AWS Public Cloud. It streams video content directly to end-users on demand, handling video encoding and global content delivery behind the scenes.

### 2. Importance of Version Control in Cloud Projects
Version control systems like Git and GitHub are critical when working with modern cloud infrastructures. In cloud engineering, infrastructure is commonly managed as code (Infrastructure as Code / IaC). Using Git allows teams to track every configuration change, audit historical updates, and roll back to a stable state if a misconfiguration occurs.

GitHub facilitates team collaboration through branches, pull requests, and peer code reviews. This ensures that infrastructure changes are validated before deployment, preventing production outages, security vulnerabilities, and accidental overwrites in live cloud environments.
