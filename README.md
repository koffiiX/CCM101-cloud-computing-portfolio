# Laboratory Activity 3: Become a Multi-Cloud Explorer

## Overview
This laboratory activity explores and evaluates the top three public cloud service providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). [cite_start]The goal is to analyze business requirements, map equivalent cloud services, and recommend appropriate cloud architecture for various enterprise client scenarios[cite: 21, 30].

## Checkpoint 7: Linux Environment Investigation

### Server System Specifications (KillerCoda Environment)
* [cite_start]**Operating System:** Ubuntu 22.04 LTS (Kernel: Linux 5.x / 6.x) [cite: 137]
* [cite_start]**CPU Information:** x86_64 Architecture, Multi-core virtual CPU [cite: 138]
* [cite_start]**Memory (RAM):** ~2 GB to 4 GB Total Memory [cite: 139]
* [cite_start]**Disk Space:** ~30 GB to 50 GB Root Partition (`/`) [cite: 140]

### Cloud Migration Hosting Options
[cite_start]If this Linux server were migrated to the public cloud, it could be hosted as an Infrastructure as a Service (IaaS) Virtual Machine using the following equivalent services[cite: 142]:

* [cite_start]**Amazon Web Services (AWS):** Amazon Elastic Compute Cloud (Amazon EC2) [cite: 142]
* [cite_start]**Microsoft Azure:** Azure Virtual Machines [cite: 142]
* [cite_start]**Google Cloud Platform (GCP):** Google Compute Engine (GCE) [cite: 142]
